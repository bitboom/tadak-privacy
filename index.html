개인정보처리방침

타닥 (Tadak) 키보드

시행일: 2026년 4월 9일

1. 수집하는 개인정보

타닥은 어떠한 개인정보도 수집하지 않습니다. 키보드에서 입력하는 내용, 사용 패턴, 위치 정보 등 어떤 데이터도 외부로 전송되지 않습니다.

2. 데이터 저장

사용자가 설정한 테마, 서체, 효과 등의 키보드 설정은 기기 내부(UserDefaults)에만 저장되며, 외부 서버로 전송되지 않습니다.

3. 네트워크 통신

타닥은 인터넷에 연결하지 않습니다. 서버 통신, 분석 도구, 광고 SDK 등을 사용하지 않습니다.

4. 전체 접근 권한 (Full Access)

타닥 키보드는 앱과 키보드 확장 간 설정 공유를 위해 전체 접근 권한을 요청합니다. 이 권한은 오직 테마 설정 동기화에만 사용되며, 키 입력 내용을 수집하거나 외부로 전송하는 데 사용되지 않습니다.

5. 제3자 제공

수집하는 데이터가 없으므로 제3자에게 제공하는 정보도 없습니다.

6. 아동 개인정보

타닥은 아동을 포함한 모든 연령의 사용자로부터 개인정보를 수집하지 않습니다.

7. 개인정보처리방침 변경

본 방침이 변경될 경우 이 페이지를 통해 공지합니다.
